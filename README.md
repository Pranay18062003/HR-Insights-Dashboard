# HR Insights Dashboard

This project focuses on analyzing HR data using Power BI to uncover insights about employee demographics, performance, and attrition trends. The goal is to transform raw HR data into actionable insights that can help organizations optimize workforce management, improve employee retention, and enhance productivity.

# Key Features

Employee Data Analysis: Explore demographics, departments, job roles, and tenure

Performance & Productivity Insights: Track KPIs, appraisals, and performance trends

Attrition & Retention Analysis: Identify patterns behind employee turnover and retention

Interactive Dashboards: Dynamic visualizations with slicers, charts, and KPIs for easy interpretation

Actionable Insights: Recommendations for workforce optimization based on data trends

# Tech Stack

Power BI – Dashboarding and visualizations

Excel / CSV datasets – HR data

DAX – Advanced calculations and metrics (optional)

# Learning Outcomes

Hands-on experience in Power BI visualization and reporting

Ability to transform HR data into actionable business insights

Improved understanding of data-driven HR decision-making

# How to Use

Clone the repository

Open the Power BI file (.pbix)

Explore the interactive dashboards and visualizations

Analyze employee metrics and performance trends
